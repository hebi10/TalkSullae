# TS-R2-01 계정 삭제 분할 처리

- 삭제 요청의 방 제한은 활성/가입 대기 방에 적용하며, 탈퇴 기록만 많아 요청 자체가 막히는 상황을 줄입니다.
- 삭제 작업은 회차별 최대 10방을 정리하며 방별 인덱스를 체크포인트로 사용합니다. 남은 방이 있으면 processing 상태로 유지하고 Auth는 모든 방 처리 후 삭제합니다. 정리 도중 실패하면 완료로 표시하지 않습니다.
- 종료/취소 경기 공개 참가자 및 결과 점수의 삭제 UID를 경기별 새 임의 식별자로 바꾸고, 자유 형식 공개 결과 문구는 개인정보 보호 안내로 대체합니다. 다른 참가자의 점수는 보존합니다. 삭제 대상의 익명 채팅 및 개인 역할/투표를 정리하는 기존 순서는 유지합니다.
- 한 방의 경기 100건/시즌 120건/메시지 대량 정리 상한은 유지합니다. 운영자 수동 검토 작업과 타인의 비공개 제출·신고 증거 등에 남는 참조까지 완전히 익명화하는 정책은 별도 검토가 필요합니다.
- 본 변경은 소스와 Emulator 검증 범위이며 운영 계정 또는 데이터를 삭제하지 않습니다.
