## 캡처와 검증
- PR HEAD에 한정된 단일 API36 phone/dark/1.0 fixture 워크플로. 10개 기본 ID와 17개 PNG 체크포인트, 12개 계측 테스트. 원본 1080×2400, manifest SHA/해시/해상도/실제 테스트 데이터 명시.
- 기존 main 수동 D01~D34 전체 캡처와 최종 4환경 QA는 변경하지 않는다. D30은 실제 ProfileScreen과 커리어 테스트 저장소를 조합한 전체 화면으로 보강한다.
- 정확한 SHA의 CI 및 네이티브 캡처 완료 전 실제 화면 대조, 병합, 완성 판정 금지. 기존 저해상도 기획 이미지의 픽셀 차이는 캡처 확보 후 정렬/인셋/화면 구성 기준으로 검수한다.
- 라이트·큰 글꼴·폴더블/실계정 및 전체 QA는 별도 검증. Firebase 운영 및 Play 변경 없음.
