## 수정 내역
1. P1 (정체 노출): 참가자 삽입 순서와 익명 별칭 공개 순서를 분리해 공개 옵션 배열만으로 정체 매핑을 재구성하지 못하도록 변경.
2. P1 (스케줄러 정체): 보관·삭제된 방 또는 활성 세션 식별자가 다른 만료 게임을 트랜잭션에서 취소하고 phaseEndsAt을 제거. 정상 게임 세션은 기존 권한 검증과 상태 전이 유지.
3. P2 (추리 선택): 완료된 일대일 선택표에서도 이미 선택한 친구를 다시 선택하면 두 별칭의 선택값을 교환하도록 변경. 서버 제출 전 정정 가능.
4. P2 (별칭 복원): 개인 상태 조회 실패를 화면에 표시하고 명시적인 동일 세션 재시도 제공.
