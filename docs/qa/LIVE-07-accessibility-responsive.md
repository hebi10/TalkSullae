# LIVE-07 — 실사용 채팅·시즌 화면의 200% 접근성 및 반응형 QA

기준: Drive 톡술래 전체화면 디자인설계 v1.0 S06/S07/S13/S18. 기존 블랙·차콜·중성 회색 컬러 시스템과 앱의 인증/서버 데이터 로직을 그대로 유지합니다.

## 구현
- 채팅은 넓은 태블릿에서도 메시지·입력창을 화면 중앙의 최대 760dp 읽기 영역에 배치하고, 말풍선은 최대 640dp로 제한합니다. 작은 폰의 기존 360dp 반응형 및 IME 인셋은 유지합니다.
- 과거 메시지를 읽는 동안 새 메시지가 도착하더라도 임의로 맨 아래로 이동시키지 않습니다. 최신 메시지로 이동 버튼을 제공하고, 사용자가 최신 위치를 보고 있을 때만 기존 자동 스크롤 정책을 유지합니다.
- 신고 사유 버튼을 200% 큰 글꼴에서 가로로 밀리지 않도록 수직 배치합니다. 접근성용 식별자와 선택 상태를 텍스트로 함께 표시합니다.
- 시즌 이동은 제목과 이전/다음 버튼을 분리하고, 랭킹 행의 참가자 이름/점수를 두 줄에 표시해 200% 글꼴에서 잘림 위험을 줄입니다.
- 에뮬레이터 캡처 스크립트의 XML element truthiness 경고를 수정하여 클릭 가능한 부모 노드 탐색의 안정성을 높입니다.

## 자동/수동 검증
- CI의 Android API 29/35/36 휴대전화, API36 태블릿 × 다크/라이트 × 글꼴 100%/200% 캡처는 기존 48장 fail-closed 기준 유지
- 실제 채팅 FakeRepository 계측과 시즌 UI 200% 테스트를 추가, 서버 멱등 전송·익명 권한 기능 변경 없음
- GitHub Actions 성공은 실제 Galaxy Fold 펼침/접힘, TalkBack 한국어 읽기 순서, Google 로그인 실계정 및 네트워크 중단/화면 회전 E2E의 대체물이 아님
- 앱 알림/초대/Firestore/Functions/Play 배포 없음; 후속 LIVE-08의 통합 검증 게이트에서 확인
