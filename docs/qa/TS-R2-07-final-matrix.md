# TS-R2-07 추가 UI 계측과 운영 검증
- 기존 4환경 수동 QA의 테스트 클래스에 온라인 방 반응형/게임 목록, 방 아이콘 저장 및 동시 수정 차단, 정책 화면의 독립 확인·계정/버전 변경 초기화·저장 중 비활성화 계측을 추가한다. 최소 테스트 수 46으로 상향.
- 정책 확인 체크 상태는 계정 및 버전 변경 시 초기화하며 미제출 상태를 프로세스 재시작에 보존하지 않는다. 로그인 상태 확인 실패 화면에서 로그아웃 동선을 제공한다.
- 테스트 APK 빌드와 전체 4환경 실제 실행을 구분한다. 최종 main SHA의 전체 QA가 실행되기 전에는 통과 처리하지 않는다.
- 운영 Firebase/API 호환, 순번 이관 활성화, 약관 공개 및 버전 승인, Play Integrity/App Check, 실제 Google 계정 다중 단말/푸시/HTTPS 링크, 실제 설치본 UI는 별도 검증한다.
- Google Play 업로드·운영 데이터 변경 없음.
