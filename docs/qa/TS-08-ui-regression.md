# TS-08 최종 UI 계측 범위
- 기존 4환경(API29/35/36 휴대폰, API36 태블릿)의 수동 QA에 프로필 편집, 초대 흐름, 큰 글꼴 시즌 전환 및 방 정보 편집 계측을 포함.
- 일반 채팅: 전송 대기 말풍선, 다음 초안 보존, 미확인 캐시 숨김 및 서버 확인 후 표시/읽음 요청 회귀.
- 프로필: 8종 캐릭터 선택 및 200% 글꼴 상태에서 저장 접근 확인.
- 방 관리: 이름 유효성, 원래 서버 revision 전달, 다른 기기 수정 이후 저장 차단 확인.
- 실제 에뮬레이터 계측 실행 결과 및 화면 캡처는 TS-10 최종 main SHA의 수동 QA에서 확인한다. PR 빌드/단위 테스트 통과만으로 계측 성공을 주장하지 않는다.
- 기존 4환경·캡처·배포 승인 정책을 유지. 서명 AAB 또는 Play/운영 Firebase 변경 없음.
