## 외부 서비스 및 공개 범위

Google 로그인과 온라인 방을 위해 Google의 Firebase Authentication, Cloud Firestore, Cloud Functions를 이용합니다. 이 서비스들은 인증, 데이터 저장, 서버 요청 처리에 필요한 정보를 처리합니다. [Firebase의 개인정보 및 보안 안내](https://firebase.google.com/support/privacy)

방 이름·설명과 멤버 표시 이름 등은 해당 방에서 권한이 있는 사용자에게 표시됩니다. Google 계정 이메일은 방 화면이나 멤버 목록에 표시되지 않습니다. 앱과 서버 간 전송에는 암호화 연결을 사용하며, 서버에서 인증 상태와 방 접근 권한을 확인합니다.

안전 신고는 이용자가 직접 보내는 경우에 처리합니다. 신고 내용은 권한이 있는 운영 담당자가 검토합니다. 관계 법령에 따라 필요한 경우 관할 기관에 신고할 수 있습니다. 신고를 위해 이미지나 영상 파일을 수집하지 않습니다.
