# 톡술래 001 — 1-B 화면별 디자인 상세 검수 (v1.1)

검수일: 2026-11-10 / 상태: **정적 디자인 QA 완료, Android 실기기 QA 미실시**
기준: 1-A PNG 24종 + GitHub 정적 HTML 프리뷰 + 001 전체 화면 기획서.
범위: 화면 S01~S18 및 S19~S24 상태/게임별 확장 시안.
검수 매체: 개별 이미지 시각 대조, Chromium Playwright 정적 렌더링, 소스/CSS 확인, 샘플 색상 대비 계산.
주의: 실제 Kotlin/Compose·Firebase 앱이 존재하지 않으며, 계정·게임·서버 권한·키보드 이벤트의 동작 검증 결과가 아니다.

## 1. 최종 판정

- 원본 1-A PNG **24개** 전수 시각 확인.
- GitHub 디자인 프리뷰 **총 27개 CSS·레이아웃·문구·상태 보정 항목** 적용 (주요 21건 + 보조 6건; 폴더블 후속 수정 별도).
- 기존 원본은 그대로 보존하고 Drive의 1-B 폴더에 **보정 캡처 12개 + 전체 미리보기 + ZIP**을 별도 기록.
- 정적 브라우저 확인: **24개 화면 × 4개 뷰포트 = 96개 조합**, 테스트 정의에 포함된 외곽 잘림·수평 오버플로·고정 푸터/입력창 가림·시각 .btn 높이 48px 미만 검출 **0건**.
- 테스트 뷰포트: 360×740, 393×852, 414×896, 600×820 CSS px. 600px S20 폴더블 2열 전용.
- 본 자동 검사는 실제 버튼 사용성, 토크백·포커스 순서, Android 폴더블·시스템 확대 글꼴을 검증하지 않는다.
- **1-B 판정: 정적 디자인 검수 통과(조건부). 1-C 상태 시안 보완과 2-A Android 구현 이후 추가 검증 필요.**

## 5. 디자인 시스템 검수

### 5.1 가독성·색상
- 기본 다크: #101114 배경, #F4F4F5 본문, #A7A9B0 보조 글자. 보조 대비 계산 약 8.04:1.
- 라이트: #F7F7F8 배경, 본문 #1B1D20, 보조 #636870, 수정된 발신자 이름 #26282D. 발신자 이름 배경 대비 약 13.78:1.
- 보조 본문 .mini, 라벨, 송신자, 메시지 시간의 일부 소형 픽셀 크기 상향. 색상 이외에 글자·체크 표시로 상태 구분.
- HTML에 표기된 px 숫자는 Android dp/sp와 동등한 실기기 결과로 간주하지 않는다. 최종 Compose에서는 시스템 글꼴 및 밀도 스케일을 사용.

### 5.2 공간·조작 영역
- .btn / .btn.tiny 최소 시각 높이를 48px로 상향하고 헤더 뒤로가기·메뉴·채팅 추가 버튼 영역 보완.
- 실제 대화 입력, 키보드 열림, 접근성 포커스, 다이얼로그 동작은 HTML 시안에 구현되지 않음.
- 360px에서 S08·S18·S19는 본문 스크롤이 필요함. 이는 허용된 디자인이며 하단 고정 액션/입력창 가림은 정적 테스트에서 검출되지 않음.
- 600px에서 폴더블 2열 프리뷰는 메뉴 180px, 채팅 패널 잔여 너비 활용; composer 하단이 인셋을 침범하지 않도록 보정.

### 5.3 게임 규칙·정보 노출
- '너 누구야?'에서 내 익명 동물 별칭은 본인만 알고, 다른 참가자는 공개 익명 별칭만 봄. 서버에 실제 매핑을 보관하고 방장에게도 사전 노출하면 안 됨.
- S11은 본인 별칭 제외 및 남은 참가자 1:1 매칭을 사용. 4/4 상태에는 각 행별 선택 완료 표시를 적용.
- S12는 시연용 3/4 적중과 +320점의 내역을 맞추어 표시. 실제 시즌 정산 정책은 별도 확정 필요.
- 라이어 채팅, 금지어, 밸런스 예측은 별개 판정 규칙을 적용. 데모 텍스트를 실제 서버 결과로 오인하면 안 됨.

## 6. 남은 이슈와 인수 조건

### 1-C — 추가 디자인 상태 정리 (P1)
1. S05 초대받은 사람 관점: 설치 전 링크, 로그인 후 승인 대기, 승인·거절·강퇴.
2. S17 계정 삭제 메뉴, 삭제 정보 범위 및 마지막 확인 화면.
3. S18 신고 접수 완료·중복 신고·차단 효과·실패/재시도.
4. S19 게임 기권·강제 종료·방 삭제·서버 결과 지연 상태.
5. S09 방장 시작 조건·일반 참여자 준비 조건을 역할별로 확정하고 상태 시안 분리.
6. S11 정체 매칭 미완료·중복 지정·마감 시 대기 및 최종 확인 상태 추가.
7. 아이콘/동물 아바타 원본 에셋 확정(현재는 이모지/임시 심볼).
8. 시즌 점수 원칙과 닉네임 공개 범위·유지 기간 정리.

### 2-A — Android 구현 후 계측
- 360/393/412dp와 태블릿/폴더블, 시스템 글꼴 100%·200%, 밝음·어두움, 제스처·3버튼 내비게이션.
- Android IME 한글 조합·채팅 입력 하단 고정·스크롤 복귀·뒤로가기/취소·포커스 순서.
- TalkBack 라벨, 실버튼 접근성 상태, 장애물 없는 48dp 입력 영역.
- Firebase 서버/Firestore 보안 규칙, 익명 ID 열람 차단, 투표 중복 제출·점수 정산 멱등성.
- 실제 단말 캡처와 정적 시안을 픽셀·기능 기준으로 대조해 이 문서를 업데이트.
