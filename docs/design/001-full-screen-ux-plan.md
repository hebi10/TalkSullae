## 1. UX 목표 및 정보 구조

### 1.1 경험의 중심
- 친구와 평소에는 채팅하고, 필요할 때 **같은 방에서 곧바로 게임**을 시작한다.
- 대표 경험은 '너 누구야?' — 주제를 선택하고 **익명으로 자유 채팅 → 말투로 친구 추리 → 정체·점수 공개**이다.
- 매 게임 뒤 동일한 멤버·방 채팅으로 돌아간다. 게임 이력과 시즌 순위는 누적된다.
- 다른 사람의 정체를 유추하는 정보가 UI·알림·접근성 읽기 순서·에러 메시지에 새지 않도록 한다.

### 1.2 탐색 계층 및 뒤로 가기
- 앱 최상위: **내 방 / 기록 / 마이** 하단 탭. 방 바깥에서만 표시.
- 방에 들어오면 **방 셸(S06)** 내부의 **채팅 / 게임 / 기록** 3개 탭. 최초 진입은 일반 채팅(S07)으로 바로 표시하고 '방 홈' 한 단계를 추가하지 않는다.
- 방 내부 상단: 좌측 나가기/뒤로가기, 중앙 방 이름·현재 멤버 수, 우측 멤버·더보기 메뉴. 열린 게임 세션 배너는 채팅 상단에 배치.
- 게임 플레이(S09~S12)에는 상위 하단 탭을 숨기고 진행 단계와 종료 확인만 제공한다.
- Android 시스템 뒤로 가기: 키보드 → 시트/다이얼로그 → 이전 상세 → 방 채팅 순서. 진행 중 게임 이탈은 확인 다이얼로그이며 세션은 서버 기준으로 유지.
- 초대 링크 진입은 로그인 여부를 확인해 초대 승인 화면(S05)을 유지하면서 돌아온다.

### 1.3 네 가지 핵심 사용자 흐름
1. 신규 사용자: S01 시작 → S02 로그인·온보딩 → S03 내 방 → S04 방 생성 → S06/S07 채팅.
2. 초대 사용자: 외부 카카오톡 링크 → S01/S02 필요 시 로그인 → S05 방 가입·승인 대기 → S06/S07.
3. 방장: S07 상단 진행 중 배너 또는 S08 게임 → S09 대기실·준비 → S10 익명 게임 → S11 추리/투표 → S12 결과 → S07 일반 채팅.
4. 기록 탐색: S03 내 방 → S06/S13 방 시즌 랭킹 → S14 연대기 또는 S16 개인 프로필.

## 2. 공통 디자인 시스템

### 2.1 컬러 및 사용 규칙
- 다크 기본 배경: #111214 / 표면: #1D1F23 / 떠 있는 패널: #282A30 / 기본 글자: #F4F4F5 / 보조 글자: #A8A9AE / 구분선: #393B40.
- 라이트 배경: #F7F7F8 / 표면: #FFFFFF / 별도 패널: #F0F1F3 / 기본 글자: #18191C / 보조 글자: #62656B / 구분선: #DADDE1.
- 기본 주요 버튼: 다크에서 #F4F4F5 배경 + #111214 글자, 라이트에서 #18191C 배경 + #FFFFFF 글자.
- 상태색은 필요한 경우만: 성공 #397C5A / 경고 #B07A28 / 오류 #BA4A4A. 비밀 역할 색은 노출될 수 있는 모든 화면에서 텍스트·아이콘도 동반하며, 게임 로직의 비밀 여부와 일치.
- 텍스트 대비 WCAG AA 기준을 충족하는지 시안 제작 후 확인. 색상만으로 경고·참가 여부를 구분하지 않는다.
- 그래디언트, 장식용 그림자, 형식적 호버 효과, 한쪽 방향만 있는 경계선은 기본적으로 사용하지 않는다. 모서리 곡률은 입력창·말풍선·시트 등 형태 구분에 필요한 정도에 한정한다.

### 2.2 타이포그래피
- 화면 제목: 22–24sp / 섹션 제목: 18–20sp / 카드 제목: 16–18sp / 본문·채팅 내용: 15–16sp / 설명: 13–14sp / 시간·보조 메타: 12–13sp.
- 한국어 시스템 글꼴 우선, 가중치는 Regular·Medium·SemiBold 중심. 영어 게임명과 숫자까지 동일한 스타일 체계.
- 제한 시간/점수/순위는 고정폭 숫자(tabular figures). 긴 닉네임은 2줄 이내 줄바꿈 후 필요한 경우 말줄임.
- 글꼴 확대 200%에서 주요 동작 버튼 접근 가능해야 하며 12sp 미만 텍스트 지양.

### 2.3 간격·레이아웃
- 간격 토큰: 4 / 8 / 12 / 16 / 24 / 32dp. 화면 좌우 16dp, 폴더블 확장형 24dp.
- 터치 영역 최소 48×48dp; 주요 버튼 높이 48~52dp; 기본 아이콘 24dp.
- 컴팩트 화면 360dp부터 세로 스크롤. 가로폭 600dp 이상은 채팅 목록과 방 정보/게임 안내를 2열로 전환하되 메시지 열 최대 폭 약 640dp로 제한.
- Status bar / navigation gesture / IME 키보드 Insets 자동 반영. 채팅 입력 하단 영역이 키보드나 시스템 바에 가리지 않게 한다.
- 작은 화면 우선. 로딩·빈 상태·긴 텍스트·네트워크 오류에서는 버튼이 화면 밖에 사라지지 않도록 한다.

### 2.4 공통 컴포넌트 목록
- AppTopBar: 뒤로/방 제목/상태/멤버·더보기 아이콘.
- MainBottomNav: 내 방·기록·마이, 선택 아이콘+텍스트.
- RoomTabBar: 채팅·게임·기록, 활성 탭 명확히 표시.
- RoomListItem: 방 아바타·이름·최근 메시지·활성 인원/게임 상태.
- Avatar: 실명 프로필·익명 동물 프로필 분리, 이미지 없을 때도 텍스트 대체.
- ChatBubble / SystemMessage / ChatComposer: 메시지·시간·보낸 상태·재시도·안전한 입력.
- ActiveGameBanner: 게임명·진행 단계·남은 시간·재참여/관전 불가 안내.
- GameCatalogCard: 게임명·최소 인원·예상 시간·한 줄 규칙·시작.
- PlayerReadyRow: 멤버·준비 상태·연결 상태. '연결 끊김'은 이름을 임의 공개하지 않음.
- Countdown / RoundProgress: 서버 마감시각 기반 남은 시간, 위험할 때만 상태색.
- VoteChoice / IdentityMatchRow: 한 명당 한 선택, 충돌·미제출 표시.
- ResultCard / ScoreDelta: 게임 결과·점수 증감·개인 성과.
- RankingRow / AchievementCard / TimelineEntry: 기간, 출처 경기, 등수, 칭호, 기록.
- EmptyState / LoadingSkeleton / ErrorPanel / ConfirmDialog / BottomSheet: 최소한의 재시도·확인 동선.

## 3. 화면별 디자인 상세 (S01~S18)

### S01 — 시작·인증 상태 화면
- 목적: 1~2초 이내 로고와 인증 확인 상태를 보여 주고 다음 목적지로 분기.
- 배치: 중앙 톡술래 워드마크와 간결한 말풍선/가면 심볼; 하단 버전 또는 짧은 상태 문구.
- 전환: 기존 로그인·온보딩 완료 → S03; 미로그인 → S02; 초대 링크 보유 → 로그인 후 S05.
- 상태: 네트워크/인증 오류면 무한 로딩이 아닌 재시도/오프라인 안내. 스플래시에 강제 재생 애니메이션 없음.
- 검증: 링크 진입·세션 만료·회전·프로세스 재생성에서도 원래 목적지 복원.

### S02 — 로그인·온보딩
- 목적: 가입 부담 최소화, 서비스 기능과 사용자 제작 채팅 정책을 짧게 설명.
- 배치: 상단 '친구와 채팅하고, 서로를 맞혀보세요'; 가운데 2~3개의 기능 설명 카드; 하단 Google 로그인 CTA·약관/개인정보 링크.
- 로그인 성공 후 닉네임 입력(최대 길이 및 중복 안내), 기본 동물 아바타 선택, 시작 버튼. 여러 입력을 한 화면에 과도하게 몰지 않는다.
- 상태: 로그인 취소·실패·이미 사용 중인 닉네임 정책·이용약관 미동의·초대 링크에서 유입됨 표시.
- 접근성: 가입 버튼을 고정 광고처럼 숨기지 않고 텍스트로 설명, 링크는 개별 터치 목표 확보.

### S03 — 내 방 홈
- 목적: 방으로 가장 빨리 진입.
- 배치: 상단 '내 방'·프로필 미니 아이콘 / 아래 진행 중 초대·승인 대기 알림 / 방 리스트(최근 활동 순) / 하단 또는 상단 '새 방 만들기' CTA.
- 방 카드: 방 이름(1줄), 멤버 수, 최근 메시지(2줄), 읽지 않음 배지, 현재 진행 게임 명(있는 경우).
- 빈 상태: '아직 참여한 방이 없어요' + '방 만들기' / '초대 코드 입력' 2개 동작.
- 상태: 방 로딩, 방 삭제됨, 초대 요청 대기, 네트워크 끊김 시 저장된 방 목록을 보여 주되 최신 여부 표시.
- 반응형: 폴더블 펼침은 방 리스트 + 선택한 방 미리보기 2열, 작을 때 단일 목록.

### S04 — 방 생성
- 목적: 필수 정보만 받고 즉시 방 생성.
- 배치: 뒤로가기·'새 방' 제목 / 방 이미지 기본값 / 방 이름(필수), 설명(선택), 공개되지 않는 비공개 안내 / 초대 승인 선택 / 생성 CTA.
- 수치: 최대 멤버 수 기본 20명; 초기에 정보 구조가 복잡해지지 않도록 추가 설정은 '고급 설정' 접기.
- 오류 상태: 길이 제한 초과·동일 이름 허용 정책·통신 실패·중복 탭 처리.
- 완료: 방 생성 후 S07로 진입하고 '친구 초대' 안내를 한 차례 보여 줌.

### S05 — 초대·가입 승인
- 목적: 카카오톡 공유 후 설치 여부·로그인 여부와 관계없이 방 가입 완료.
- 방장: 초대 링크 복사·카카오톡 공유·만료 시간·링크 재발급/폐기. 가입 요청 목록에 승인·거절 버튼.
- 초대받은 사람: 방 이름·설명·멤버 수·방장 표시 / '가입 요청' CTA / 승인 대기 / 승인 완료 입장.
- 예외: 만료 링크, 무효 코드, 이미 가입됨, 이전 강퇴 계정, 가입 거절, 로그인 필요.
- 보안 UX: 실시간 채팅 내용·게임 기록은 가입 승인 전 노출하지 않음.
- 설치 유도 웹의 역할은 링크·코드 보존 안내이며 카카오톡의 기존 단체 채팅방에 자동 참여시키지 않는다.

### S06 — 방 셸(방 내부 공통 레이아웃)
- 목적: 동일 방에서 채팅·게임·기록을 이동시키는 재사용 컨테이너. 추가 클릭이 필요한 독립 대시보드가 아님.
- 상단: 방 이름 / 멤버 수·온라인 상태의 확인 가능한 범위 / 초대·멤버 관리 아이콘 / 더보기.
- 본문 상단 탭: '채팅' '게임' '기록'. 최초 진입의 기본 탭은 채팅(S07).
- 하위 화면 전환 동안 같은 roomId·활성 세션 상태를 유지. 뒤로가기는 방 밖 내 방 홈(S03)으로.
- 폴더블: 좌측 대화 목록 또는 참여자 패널과 우측 선택 탭을 나란히 배치하는 확장형 고려.

### S07 — 일반 채팅
- 목적: 평소 사용을 막지 않으면서 게임 시작이 쉬운 채팅 경험.
- 배치: S06 상단 공통 바 → 진행 중 게임 배너(있는 경우) → 날짜 구분 메시지 리스트 → 입력창·전송.
- 메시지: 내 메시지는 오른쪽, 상대는 왼쪽; 상대 이름·아바타, 시간, 전송·실패/재전송 표시. 긴 URL·대용량 텍스트 줄바꿈.
- 새 메시지: 아래쪽을 읽는 중에는 자동 하단 스크롤; 과거 메시지를 읽는 중에는 '새 메시지 N개' 버튼을 띄우고 임의 이동 금지.
- 시스템 메시지: 멤버 입장·퇴장, 게임 시작·종료, 기록 달성. 신고·차단은 메시지 길게 누르기 메뉴.
- 빈 상태: '첫 메시지를 보내보세요'와 초대 안내. 통신 실패 시 전송 실패·다시 보내기, 동기화 지연.
- 키보드: 입력 상태를 보존하고 IME 위에 입력창을 배치; 타이핑할 때 화면 전체가 불필요하게 점프하지 않음.
- 게임 중에도 일반 채팅 기록과 익명 게임 채팅을 혼합하지 않음.

### S08 — 게임 카탈로그·규칙
- 목적: 인원·난이도·게임 시간을 기준으로 빠르게 고르기.
- 상단: '어떤 게임을 할까요?'와 참여 가능 인원 정보 / 우선 4개 카드(너 누구야?, 라이어, 금지어, 밸런스 예측).
- 카드: 게임 아이콘, 이름, 한 줄 설명, 최소~최대 인원, 예상 시간, '규칙 보기'와 '대기실 만들기'.
- 규칙은 바텀 시트로 간단히, 자세한 규칙은 스크롤. 대기실 생성 시 방 내 하나의 활성 실시간 세션 정책 검사.
- 참여 불가 상태: 인원 부족·이미 시작된 경기·방장만 시작 허용. 단순 회색 비활성보다 이유 설명.
- 향후 자체 문제 제작은 이 화면에 '내 문제' 섹션으로 확장하고 첫 MVP에서는 노출하지 않음.

### S09 — 게임 대기실
- 목적: 시작 전에 인원·규칙·준비 여부를 명확히 확인.
- 배치: 상단 게임명과 규칙 한 줄 / 인원 충족 표시(예: 4/6) / 각 멤버 아바타·닉네임·준비·연결 상태 / 하단 '준비 완료' 또는 방장의 '시작' 버튼.
- 방장 시작: 최소 인원 충족 및 필수 준비 완료 시 활성화. 인원/시간/라운드 설정은 게임 시작 전만 수정.
- 상태: 대기실 나가기, 중복 참가, 연결 끊김, 방장 오프라인, 동시 게임 생성 오류.
- 시작 직전 개인정보 유출 방지: 실제 역할과 익명 별칭은 본인에게만 배정 결과를 표시한다.

### S10 — 실시간 게임 플레이·채팅
- 목적: 한 화면에서 '누가/무엇을/언제까지 해야 하는지' 파악.
- 배치(상→하): 게임명+나가기 아이콘 / 라운드 번호+남은 시간 / 주제 또는 개인 역할 안내 / 참가자 익명 아이콘 스트립 / 실시간 메시지 리스트 / 하단 입력창.
- '너 누구야?': 모든 참가자에게 동일한 질문 배너; 본인에게만 자신의 익명 동물 이름 표시, 상대는 익명 동물 이름만 표시. 실제 이름·입장 순서·실제 프로필 숨김.
- '라이어': 본인에게만 라이어 역할 또는 공통 주제 안내. 역할 안내는 접기 가능하지만 본인 역할 재확인은 허용.
- '금지어': 내 금지어는 보이지 않음; 다른 사람 금지어는 게임 규칙에 따라 볼 수 있음. 금지어 발생 시 서버 확정 탈락 안내.
- '밸런스 예측': 채팅보다 A/B 선택 카드가 우선; 미제출 멤버 수 표시, 다른 사람 답은 마감 전 숨김.
- 타이머: 마지막 30초에 작게 강조, 0초 후 입력 비활성 및 '추리/투표로 이동' 안내. 클라이언트 시간 조작 불가.
- 초대·정체·서버 메시지: 익명 플레이 중 실제 사용자 ID, 실제 프로필 사진, 알림 발신자에 실제 닉네임 미노출.
- 상태: 연결 중/재접속, 서버 중단, 늦게 입장, 채팅 금지, 참여하지 않은 멤버의 비밀 정보 차단.

### S11 — 추리·투표 제출
- 목적: 투표 오동작·누락을 줄이고 정답 공개 전 선택 보장.
- '너 누구야?': 각 익명 동물 이름마다 실제 참가자 한 명 선택. 본인 익명 닉네임 제외, 한 명을 둘 이상에 중복 지정 불가. 선택 충돌시 행 아래 메시지.
- '라이어': 의심하는 익명 또는 실명 참가자 1명 선택. 익명 여부는 게임 설정에 따름. 최종 제출 시 확인.
- '밸런스 예측': A/B 선택 및 친구의 선택 예측. 각 필수 문항이 완료되지 않으면 제출 비활성.
- 공통: 남은 시간/응답 진행 수/취소 가능 상태/제출 CTA. 제출 후 결과 대기 화면, 내용 수정은 게임 규칙이 허용할 때만.
- 마감: 제출 없이 시간 초과되면 미제출/기권 처리, 사후 선택 변경 불가. 서버 응답 성공 후에만 '제출 완료' 표시.

### S12 — 결과·정체 공개
- 목적: 정답·승리 여부·점수 증가를 혼동 없이 보여 주고 다시 방에 복귀.
- 상단: 라운드 결과(성공/실패/승리 팀), 본인 성과 강조(정답 3/5, +300 등).
- 본문: 익명 프로필 ↔ 실제 프로필 짝짓기, 다른 참가자 투표 결과, 보너스 내역, 통합 시즌 포인트 변화.
- 하단: '방으로 돌아가기' 기본 CTA / 권한이 있는 경우 '다음 판 준비' 보조 액션.
- 연출: 정체는 사용자가 결과로 전환한 이후에 공개; 짧은 애니메이션 1회만, 동작 감소 설정 존중.
- 정산 지연/실패: 점수 확정 전 상태를 명확히 표시, 잠정 점수를 확정처럼 보여주지 않음.
- 한 판 결과는 영구 기록에 저장하되 게임 채팅 전체 공개 여부는 별도 정책.

### S13 — 방 랭킹·시즌
- 목적: 지금 누가 앞서는지, 어떤 기록이 누적됐는지 빠르게 비교.
- 상단: 시즌명·기간·종료 예정일, 현재 순위 요약. 1~3위를 읽기 쉬운 리스트 또는 작은 시상 영역으로 표현.
- 본문: 멤버별 순위·점수·변화량, 게임 유형 필터, 지난 시즌 선택. 긴 목록은 스크롤.
- 상세: 랭킹 행 선택 시 해당 멤버의 '방 기준' 통계만 표시. 다른 방 사생활 정보 없음.
- 상태: 시즌 시작 전·참여 인원 부족·기록 없는 방·데이터 조회 오류; 점수 동률은 공동 순위 정책 표시.
- 주의: 단순 플레이 횟수가 실력처럼 오해되지 않도록 승률·정답률·참여 수를 별도 표시.

### S14 — 방 연대기
- 목적: 함께한 시간이 쌓이는 느낌을 제공.
- 배치: 연/월 필터 → 타임라인 목록 → 경기 결과 카드, 시즌 우승·최고 기록·기념 업적.
- 카드: 날짜, 기록 유형, 관련 멤버, 요약 수치, 게임 상세로 이동. 채팅 원문 자동 공개 금지.
- 빈 상태: '첫 게임을 시작하면 이곳에 기록이 쌓여요' + 게임 선택 이동.
- 기록 조회 실패와 기록이 없음을 구별하고, 삭제된 멤버는 익명 처리 규칙 적용.

### S15 — 방 멤버 관리·방장 설정
- 목적: 초대와 권한을 안전하고 단순하게 운영.
- 상단: 방장 표시, 현재 멤버·초대 요청 수 / '친구 초대' CTA.
- 목록: 프로필·닉네임·역할·가입일, 승인 대기 목록 / 방장이 선택한 멤버 액션(강퇴).
- 강퇴: 사용자 이름·영향 범위·재참여 제한을 명시한 확인 다이얼로그. 즉시 강퇴가 아닌 최종 확인.
- 방장 위임: 대상 선택·위임 후 권한 변경 설명·확인. 방장 탈퇴 시 위임을 먼저 요구.
- 일반 멤버에게는 멤버 목록과 신고/차단만 표시; 관리자용 버튼 자체를 숨기되 서버 권한 검사도 수행.

### S16 — 내 프로필·업적
- 목적: 개인의 게임 성장과 과거 활동 확인.
- 상단: 아바타·닉네임·대표 칭호·레벨·경험치. 편집 아이콘은 프로필 편집 이동.
- 요약: 총 경기, 누적 승리, 정답률, 자주 플레이한 게임. 게임별 필터로 기록 탐색.
- 업적: 배지 그리드·획득일·획득 조건, 미획득은 잠금 상태와 조건 설명.
- 방별 통계: 내 참여 방 중 선택한 방 기준으로만 해당 멤버와의 전적 표시.
- 상태: 첫 플레이 전, 프로필 이미지 없음, 공개 설정 제한, 통계 갱신 중.

### S17 — 설정
- 목적: 계정·알림·디자인·개인정보 제어.
- 그룹: 계정/닉네임, 알림(일반 메시지·게임 시작·초대 요청), 화면 테마(시스템·라이트·다크), 고객지원·신고 정책, 약관·개인정보처리방침, 로그아웃, 계정 삭제.
- 토글과 설명은 라벨을 함께 표시, 알림 권한 미허용이면 OS 설정 이동을 안내.
- 위험 행동은 맨 아래에 모으고 삭제 범위를 확인. 앱에 실제로 구현되지 않은 설정은 보여 주지 않음.
- 상태: 서버 연결 실패, 변경 저장 실패, 계정 삭제 불가/진행 상태.

### S18 — 신고·차단·안전
- 목적: 채팅 기반 서비스의 사용자 보호와 앱스토어 정책 충족.
- 경로: 채팅 메시지 길게 누르기 → 신고·차단, 멤버 목록 → 신고/차단, 설정 → 차단 계정 목록.
- 신고 폼: 대상 표시, 신고 사유 단일 선택, 상세 사유 선택 입력, 관련 메시지 자동 참조(가능한 범위), 제출.
- 제출 후: 접수 완료 상태·추가 문의 안내. 신고자와 신고 상세는 상대 멤버에게 노출하지 않음.
- 차단: 차단 효과(메시지 표시·알림·방 활동에 미치는 실제 범위)를 정확히 안내하고 해제 가능하게 한다.
- 상태: 중복 신고, 네트워크 실패, 신고 불가 대상, 관리자·사용자 권한 혼동 방지.

## 4. 게임별 주요 화면 변형

### 4.1 너 누구야? — 대표 화면 스토리보드
1. 게임 카드: '말투를 숨기고, 친구의 정체를 맞혀보세요.'
2. 대기실: 실제 멤버 닉네임·준비 상태 확인.
3. 시작: 본인에게만 동물 가면/익명 이름 공개(예: 부엉이), 익명 별칭 변경 불가.
4. 주제 배너: '우리 중 무인도에서 가장 잘 버틸 사람은?'
5. 익명 채팅: 프로필은 동물 아이콘·익명 이름만 표시, 입력창 고정.
6. 종료 30초: 남은 시간 강조, 메시지 작성 계속 허용.
7. 추리: '고양이 = 민수?'처럼 각 익명 ↔ 멤버 지정. 본인 제외·중복 지정 불가.
8. 결과: 가면/실제 프로필 연결, 맞힌 수, 위장 점수, 시즌 포인트 반영.
- 금지: 참여 순서·메시지 순번·전송 메타·알림 내용으로 실제 사용자를 역추적할 수 있는 UI.

### 4.2 라이어 채팅
- 역할 카드: 일반 사용자에게만 주제 표시, 라이어에게는 '당신은 라이어입니다'.
- 채팅: 주제 직접 노출 금지, 참가자 개별 지목 UX는 규칙에 따라.
- 투표: 한 사람 선택, 동점 시 재투표 안내, 라이어 적발 시 주제 추리 입력.
- 결과: 팀 승패·정체·투표 명세·반영 점수.

### 4.3 금지어 채팅
- 각 상대의 금지어 보기 패널을 채팅 상단 별도 영역에 제공, 내 금지어는 숨김.
- 금지어 감지는 서버 확정으로 표시; 채팅 메시지 강조·탈락 안내·생존 멤버 수.
- 오탐 방지를 위해 MVP는 명확한 문자열 규칙 사용; 의미 추론 판정 UI 금지.

### 4.4 밸런스 예측
- 두 개 선택 카드(A/B) → 내 선택 잠금 → 친구 선택 추리 → 마감 후 결과.
- 비동기일 때에는 방 홈의 진행 중 카드에 남은 기한·참가 인원·내 제출 여부 표시.
- 내 제출 전 다른 사람의 선택 비율·실명 공개 금지.

## 5. 공통 상태·오버레이·반응형 체크

### 5.1 반드시 디자인할 상태
- 최초 진입 / 빈 목록 / 기본 데이터 로딩 / 부분 동기화 / 통신 실패 / 오프라인 캐시 / 재시도
- 초대 만료 / 가입 승인 대기 / 초대 거절 / 강퇴 / 방 삭제 / 권한 변경
- 게임 참가 모집 / 준비 완료 / 인원 부족 / 역할 배정 / 채팅 / 30초 경고 / 마감 / 제출 대기 / 결과 / 점수 정산 지연
- 앱 강제 종료 복귀 / 타이머 서버 재동기화 / 본인 기권 / 방장 오프라인
- 키보드 열림 / 폴더블 펼침 / 다크·라이트 / 글자 크기 200% / 긴 닉네임·긴 메시지
- 일반 채팅 알림과 익명 게임 알림이 동시에 도착하는 상황 (비밀 정보 누출 금지)

### 5.2 모달·시트 기준
- BottomSheet: 게임 규칙, 정렬·필터, 방 정보 등 짧은 맥락 작업.
- Dialog: 강퇴, 방장 위임, 게임 탈퇴, 삭제, 최종 투표 제출 확인 등 되돌리기 어려운 작업.
- Full Screen: 익명 게임 채팅, 추리·투표, 결과 공개 — 메시지 화면과 타이머를 함께 읽기 위해 독립 페이지.
- 팝업으로 중요한 선택을 가리거나 작은 단말에서 스크롤이 막히는 구조 금지.

### 5.3 QA 타깃
- 화면 폭 360dp / 393dp / 412dp / 600dp 이상(폴더블 펼침, 양분할).
- 라이트·다크, 100%·200% 텍스트 스케일, 제스처·3버튼 내비게이션.
- 긴 텍스트·한글 조합 중 키보드·네트워크 오류·화면 회전 및 프로세스 종료.
