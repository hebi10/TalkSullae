# TS-07 보존 정책 및 운영 비용 확인
- 기존 시간당 메시지 정리 작업에 만료된 roomOperationLimits 문서 정리를 추가. 회차당 최대 1,000건, 서버 트랜잭션에서 만료 시각 재확인으로 동시 갱신 문서를 보존.
- 구버전 일반/게임 채팅의 createdAt/expiresAt만 투영 조회하는 counts-only 감사 도구. 원문/닉네임/UID/문서 경로를 출력하지 않고 90일/7일 정책에 따른 만료 후보, 기존 만료일, 잘못된 날짜 및 스캔 상한을 집계한다.
- 실행 전 운영 프로젝트, 명시적 승인, 최소한의 감사 전용 접근 권한 및 예상 읽기 비용을 확인한다. functions 폴더에서 `node scripts/audit-retention.js --project talksullae --max-documents 2000`. 기본 그룹당 최대 2,000문서, 두 그룹 최대 4,000문서 읽기 범위(쿼리 및 색인 비용은 별도). complete=false이면 전체 집계가 아니다.
- 감사 결과와 보존 정책을 검토하기 전 과거 문서에 만료일을 일괄 추가하거나 삭제하지 않는다. 실제 운영 감사·스케줄러 배포·비용 측정은 별도 작업. 운영 Firebase/Play 변경 없음.
