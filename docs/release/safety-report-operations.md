# 톡술래 안전 신고 운영

이용자는 `마이 → 설정 화면 → 안전 신고`에서 Google 로그인 후 신고를 접수합니다. 신고는 톡술래 Firebase 프로젝트의 Cloud Firestore `(default)`에 있는 `safetyReports` 컬렉션에 쌓입니다. 앱에 표시되는 신고 번호는 문서 ID입니다. Firebase Console에서 프로젝트 권한이 있는 담당자가 `status`가 `received`인 문서를 확인할 수 있습니다.

1. `child_safety` 신고를 우선 확인합니다. 신고 번호와 작성 시각, 방 참고 정보, 신고 내용을 바탕으로 해당 상황을 확인합니다. 보고자 UID와 신고 내용은 관련 업무를 맡은 담당자만 확인합니다.
2. 앱에서 관리할 수 있는 콘텐츠나 계정의 위반이 확인되면 공개 아동 안전 표준에 따라 접근 제한, 삭제 또는 이용 제한을 적용합니다. 확인된 아동 성적 학대물은 관련 법령에 따라 관할 기관에 신고합니다. 자료를 내부 채팅이나 이메일로 복제·전달하지 않습니다.
3. 조치 결과와 시각은 권한이 제한된 운영 기록에 남기고 Firestore의 처리 상태를 갱신합니다. 신고 처리와 법령상 보존에 필요한 기간이 끝난 기록은 담당자가 검토해 정리합니다.

접수 서버는 `asia-northeast3`의 `submitSafetyReport`입니다. 클라이언트의 직접 읽기·목록·쓰기는 Firestore 규칙으로 차단합니다. 앱 재시도에 의한 중복은 같은 요청 ID로 처리하고, 새 신고는 계정당 60초 간격으로 제한합니다.
