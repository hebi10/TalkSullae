# TS-06 친구 상세 전적
- 기획서의 현재 같은 방 멤버 전적, 함께한 경기, 상대 점수 비교, 정체 추리 적중률 및 밸런스 선택 일치율을 구현.
- 친구 누적 전적은 해당 방 playerStats만 집계. 다른 방, 비활성 멤버, 삭제 요청 중 계정의 정보 조회를 차단. 직접 SDK의 타인 playerStats 접근 금지 정책을 유지.
- 비교는 내 최근 최대 30개 정산 기록에서 함께 참가했고 서버 phase=finished인 경기만 계산한다. 따라서 함께한 경기 수는 전체 누적 횟수가 아니라 명시된 조회 범위의 집계이다. 원점수 비교는 경기 단위로 제한한다.
- 정체 추리 및 밸런스 일치 비율은 서버의 종료된 세션에 있는 유효 제출을 집계하되 비밀 원문, alias, 투표 대상, 개별 경기 ID 및 개인 선택을 반환하지 않는다. 미제출 또는 삭제된 기록은 분모에서 제외한다. 상대가 정체를 틀린 횟수는 의도적인 속임을 증명하지 않는다.
- 사용자별 분당 6회 호출 제한. 최대 30경기 조회로 최악의 경우에도 한 요청의 읽기 범위를 제한하며 실제 운영 비용 및 지연은 측정 필요. 신규 데이터 영구 저장 없음.
- 방 종료 시 하위 전적/시즌/연대기 조회 차단 보강. 기록 화면에서 서버 확인 전 캐시-only 데이터를 표시하지 않음. Android 단위/계측 및 Firebase Emulator 회귀 테스트 추가. 신규 callable 운영 적용 전 배포 게이트 통과 필수.
