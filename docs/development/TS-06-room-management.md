# TS-06 방 관리
- 방장만 이름·설명·신규 가입 승인 설정을 수정. 서버 트랜잭션으로 활성 멤버, 계정 삭제 상태, roomRevision 및 정원 정합성을 검증. 활성/대기 사용자의 방 목록 이름을 일치시키며 기존 승인 대기 요청은 유지.
- 방 종료는 명시적 확인 후 활성/대기 멤버 접근 권한과 초대 코드를 무효화하는 archive 동작. 게임 진행 중에는 차단. 원문 기록 및 신고 증거를 즉시 영구 삭제하지 않으며 기존 보존 정책에 따름.
- 구버전의 방장 탈퇴 경로도 진행 중 게임을 종료하도록 제한.
- 새 callable updateRoom/archiveRoom은 운영 호환성 게이트에 포함. 운영 Firebase/Play 변경은 별도 승인 대상.
- 검증: 기존 방 서비스 테스트 및 이름 동기화, 권한, 동시 수정 방지, 활성 게임 차단, 초대 무효화, 기록 보존, 중복 종료 회귀 테스트. 최신 PR CI 확인 전 완료 처리 금지.
