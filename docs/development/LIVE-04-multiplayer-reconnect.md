# LIVE-04 — 일반 채팅·게임 4종의 재접속 및 서버 상태 통합

기준: LIVE-03 PR #53 상위 브랜치. Android Google 로그인·Firebase 권한/보안/게임 엔진 유지.

## 실제 구현
- 활성 방의 Firestore \`activeGameSessionId\`가 변경되면 채팅/게임 목록 위에 진행 중 게임 배너를 표시합니다. 서버의 공개 세션 문서로만 게임 종류/라운드/단계(대기·플레이·투표)를 확인하고, 다른 사용자의 익명 역할과 비공개 답안은 가져오지 않습니다.
- 이어하기 선택 시 실제 게임 종류별 기존 ViewModel의 서버 세션/개인 역할 복원 경로를 사용합니다. 방을 새로 만들거나 임의로 게임 결과를 계산하지 않습니다.
- 일반 채팅의 읽기 실패는 명시적인 다시 연결 버튼으로 복구합니다. 리스너 재구독 시 입력 중이던 초안과 멱등 메시지 재시도 요청 ID를 보존하며, 다른 방으로 이동하거나 실제 로그아웃하면 기존 ViewModel의 상태 정리를 유지합니다.
- 이전의 타이머/서버 단계 변경, 4종 결과 정산, Firestore 비밀 역할 권한은 변경하지 않습니다.

## QA/미검증
- 기존 GAME-06 4게임 연속 세션·단일 정산·역할 유출 방지 Emulator/Android 검증 유지.
- 재구독 시 채팅 초안 보존 단위 테스트 추가. 실제 네트워크 단절/재접속 및 실계정 4~10명 테스트는 운영 Firebase 승인 이후 별도 필요.
- 푸시·초대 배포, Firebase Functions/Rules/Indexes/Scheduler 운영 반영, Google Play AAB/트랙/스토어 변경 없음.
