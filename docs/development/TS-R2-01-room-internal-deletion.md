# TS-R2-01 방 내부 계정 삭제 분할
- 기존 방 10개 단위 작업을 개인 경기 기록·일반 메시지·시즌 점수·게임 세션·멤버 정리 단계로 나눈다. 소유한 행은 회차당 최대 100개, 시즌 40개, 세션 20개씩 처리한다. 방 내부 문서 ID 진행 위치를 기존 개인 방 인덱스의 서버 관리 체크포인트에 저장한다. 체크포인트는 성공 후 이동하고 마지막에 인덱스를 지운다.
- 이전 경기 100건·시즌 120건·메시지 10000건의 전체 상한을 제거한다. 현재 활성 방 100개를 초과하는 삭제 접수는 기존 검토 조건을 유지한다. 45초 작업 예산과 스케줄러 동시성 1, 540초 제한을 둔다.
- 삭제 접수 후 활성 경기 참가 여부와 방장 상태를 재확인한다. 타인 활성 게임은 수정하지 않고, 종료 경기에서만 삭제 대상 메시지·역할·제출·행동 영수증과 호출 제한을 정리한다. 다른 참가자의 원문 및 점수는 유지한다.
- 신고 작성자 식별자 정리도 100건씩 진행한다. 법령/안전 대응에 필요한 기존 신고 증거, 타인의 제출, 초대 발급 이력 등의 별도 보존 기준은 운영 정책 검토 대상이다. 계정 소유 하위 문서 정리 및 Auth 삭제 완료 전 완료를 표시하지 않는다.
- Firebase Emulator에서 101개 종료 세션, 121개 시즌, 101개 일반 메시지와 남아 있는 타인 메시지의 재개·정리 검증을 추가한다. 실제 운영 계정 삭제 없음.
