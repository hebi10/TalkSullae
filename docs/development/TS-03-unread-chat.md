# TS-03 새 메시지 및 최근 대화 표시
- 전송 트랜잭션에서 활성 멤버(최대 20)의 사용자별 방 인덱스에 마지막 활동 시각/메시지 ID 및 다른 사람이 보낸 새 메시지 수를 갱신. 원문/닉네임을 복제하지 않고 중복 요청은 카운트하지 않는다. 대기·강퇴·종료 멤버는 대상에서 제외.
- 서버가 현재 최신 ID와 사용자의 인덱스 최신 ID가 일치할 때에만 자기 읽음 수를 0으로 변경. 새 메시지와 동시에 읽어도 뒤늦은 요청은 새 메시지를 지우지 않는다. 0인 경우 추가 쓰기 없음.
- 앱은 현재 화면 resumed, 최신 메시지가 화면에 실제 노출, 최신 위치, 서버 동기화 및 권한 확인 상태일 때만 읽음 요청. 실패 시 거짓 성공 처리 금지.
- 새 기능 적용 이후 수신 이벤트만 집계(과거 기록 소급 없음). 삭제 표시/만료 정책과 별개로 마지막 확인 이후의 신규 이벤트 수이며 99+ 표시, 마지막 활동이 90일 이상 지났으면 배지 숨김. 새 대화가 90일 공백 후 발생하면 카운터 재시작.
- 비용: 메시지당 추가 방 메타데이터 쓰기 1건 + 활성 멤버별 인덱스 최대 20건과 활성 멤버 쿼리. 홈 화면 별도 방별 listener나 메시지 원문 복제 없이 목록 인덱스를 재사용. 운영 사용량/지연 측정 후 확장 정책 검토.
