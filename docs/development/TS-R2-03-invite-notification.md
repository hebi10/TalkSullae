# TS-R2-03 초대 및 알림 접근성
- 현재 초대만 방장이 취소할 수 있도록 서버 권한 및 예상 해시를 검증한다. 신규 발급과 동시 충돌하면 취소하지 않는다. 기존 가입자/대기자는 유지하고 재시도는 멱등 처리한다.
- FCM은 기존 원문 없는 payload를 사용한다. 수신 계정/종류/방 ID를 검증하고, 앱에서 현재 로그인 계정 및 활성 방 목록 확인 후 채팅 또는 게임 탭으로 이동한다. 계정 불일치·탈퇴·강퇴 상태는 열지 않는다. 게임은 진행 중 배너를 통해 서버 확인 후 이어간다.
- 가입 화면의 기존 개인정보처리방침 링크를 노출한다. 최종 이용약관·개인정보 고지 및 버전 동의 저장 요구사항은 확정 후 추가. 새 동의를 임의로 저장하거나 법률 검토 완료로 표시하지 않는다.
- HTTPS 초대 공유는 Hosting 소유 및 Play 서명 인증서 확인 이후 활성화한다. 실제 운영 설정과 FCM 다중 단말 검증은 별도.
