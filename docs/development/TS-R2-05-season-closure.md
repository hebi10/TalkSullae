# TS-R2-05 월간 시즌 마감 및 공동 우승
- 월간 시즌의 Asia/Seoul 달력 경계와 기존 점수 산식 유지. 월 종료 10분 후 서버에서 최종 결과를 확정한다. 정상 경기 정산은 해당 시즌 문서를 읽어 마감 결과가 있는 시즌에 점수를 추가하지 않는다. 스케줄러의 게임 자동 진행은 각 호출의 현재 서버 시각으로 정산한다.
- 신규 정산은 시즌당 한 번의 마감 대기열 문서를 생성한다. 기존 매시간 정리 스케줄러가 기한 도래 20개씩 처리한다. 과거 데이터에 대기열이 없어도 기존 시즌 조회 시 마감 가능. 최종 값(최고 점수, 공동 우승자 수, 경기 수, 마감 시각)을 시즌 문서에 저장하며 개인 UID/닉네임 목록은 복제하지 않는다.
- 시즌 기록 화면은 확정 최고 점수와 우승자를 보존된 순위에서 표시한다. 상위 20명만 표시한다. 삭제한 우승자의 점수 문서가 사라져도 차순위를 우승자로 승격하지 않는다.
- PR #93의 계정 삭제 분할 단계와 통합: 종료된 시즌에서 본인 점수 삭제 전 같은 트랜잭션으로 마감 결과를 확정한다. 월 종료 직후 10분의 마감 유예 중이면 체크포인트를 이동하지 않고 이후 회차에 재개한다. 이미 제거된 과거 점수의 역사적 우승 결과는 복원할 수 없다. 기존 활성 시즌 점수 삭제는 보존 정책을 유지한다.
- 마감 결과에는 모든 개인 정보가 제거된 뒤에도 집계 값만 남는다. 운영 보존 정책, 실제 Scheduler 및 Firebase 상태는 별도 확인 대상이며 이 작업에서 배포하지 않는다.
