# TS-R2-04 온라인 화면 레이아웃
- 실제 온라인 방 채팅/게임/기록 화면에서 방 제목·활성 인원·방 목록 이동 및 멤버 관리 탭의 동선을 통일.
- 600dp 이상은 184dp 방 정보·탐색 영역과 나머지 콘텐츠 영역을 분리. 작은 화면은 기존 단일 영역을 유지. 채팅 화면 중복 헤더 제거.
- 게임 목록에 서버 카탈로그와 규칙 기준 참가 인원, 예상 시간, 설명을 표시. 대기실/권한/진행 중 게임의 서버 판정은 변경하지 않음.
- 방 목록은 이름 기반 아이콘과 기존 상태·최근 시각·읽음 배지를 유지. 사용자 지정 아이콘과 목록의 정원·게임 상태 동기화는 TS-R2-06 후속 범위.
- 폴더블 실제 화면 및 키보드/회전/200% 글꼴은 최종 계측에서 검증. 기존 디자인 컬러와 컴포넌트 유지.
