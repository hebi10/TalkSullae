# LIVE-02 — 데모 홈에서 실제 온라인 탐색으로 전환

기준: LIVE-01 PR #50(`df23ac4`) 후속 스택. Google Drive 톡술래 전체 UI/UX 명세의 S01~S03, S06~S08, S13, S16 기준을 보존합니다.

## 동작
- 인증·프로필이 있는 사용자는 홈의 내 방/기록 탭에서 실제 Firebase `userRooms/{uid}/rooms`를 구독합니다. 로컬 샘플 방·가짜 랭킹·데모 기록은 온라인 사용자의 기본 동선에서 제거합니다.
- 방 목록을 최근 변경순으로 표시합니다. 로딩·빈 목록·조회 실패를 구분하고 재시도 버튼을 제공합니다. 승인 대기자는 승인 전 방 내용에 접근하지 않습니다.
- 방 입장 즉시 실제 채팅으로 이동합니다. 방 내부 상단의 채팅/게임/기록/멤버 탭을 통해 서버 게임 4종·기록·멤버 관리 화면으로 이동합니다. 게임 화면은 서버 세션 뷰모델을 유지합니다.
- 메인 기록 탭은 실제 가입 방별 기록 선택 화면입니다. 무소속 사용자를 위한 별도 전역 랭킹을 새로 발명하지 않습니다.
- Google 로그인/닉네임 프로필을 만든 사용자에게 데모용 “Firebase 관리” 메뉴를 노출하지 않습니다.
- Firebase 미연결 디버그 빌드에 한해서 기존 로컬 UI/계측 캡처 체험 경로를 보존합니다. 정식(Release) 빌드에서는 데모 진입을 숨깁니다.
- 레거시 데모 구성요소의 실제 소스 삭제는 QA 캡처 분리 후 별도 작업으로 남기며, 프로덕션 화면에서는 사용하지 않습니다.

## 검증과 미완료
- Android API 29/35/36 휴대폰·API36 태블릿·Compose 기존 데모 QA, Firebase 보안 에뮬레이터 회귀·OPS-08 배포 정책 유지.
- 실제 Firebase 배포, Play 설치본의 Google 로그인·방 목록 로딩, 실기기 네트워크 오류·인수는 확인되지 않았으며 별도 QA가 필요합니다.
- LIVE-03에서 카카오톡 공유 링크, 가입 승인 및 멤버 관리 UX 개선을 별도 PR로 이어갑니다.
- Play AAB/스토어/트랙·Firebase 운영 변경 없음.
