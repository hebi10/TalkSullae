# TS-R2-05/06 보존된 개인 전적과 성장 기록
- 기존 getMyCareer 빈 요청은 활성 방 집계와 기존 응답을 유지한다. 새 앱은 scope=retained 요청으로 25개 방 인덱스 단위 개인 전적을 조회한다.
- 동일 읽기 전용 트랜잭션에서 인증 계정의 삭제 상태, 방 인덱스, 실제 본인 멤버 상태 및 본인 playerStats만 검증한다. 과거 방 이름·채팅·다른 사용자 전적·비밀 제출을 반환하지 않는다. 탈퇴/강퇴/종료된 방에서도 보존된 본인 전적만 조회한다.
- 서버에 아직 보존된 기록을 재사용하며 별도 영구 원본 저장이나 데이터 보존 기간 연장을 수행하지 않는다. 계정 삭제 또는 향후 확정된 데이터 파기 정책은 그대로 적용된다.
- 페이지당 최대 25방과 확인용 인덱스 1건을 읽으며 미완료 시 추가 조회 버튼 및 부분 집계 안내. 모두 조회한 뒤에만 기존 경기당 10 XP, 100 XP당 1레벨 계산을 표시한다. 페이지 간 새로운 경기 정산 등으로 숫자가 바뀔 수 있어 새로고침 제공.
- 정확한 영구 경험치 별도 원장, 공식 시즌 마감 스냅샷은 별도 정책/검증이 필요하다. 운영 Firebase/Play 변경 없음.
