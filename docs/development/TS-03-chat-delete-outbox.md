# TS-03 메시지 삭제 및 미전송 복구

- 본인 일반 채팅 메시지 삭제는 서버 트랜잭션으로 활성 방/멤버/작성자/계정 삭제 상태를 확인한다. 원문을 공개 문서에서 제거하고 삭제 표시를 남긴다. 같은 전송 요청으로 삭제 메시지를 재생성하지 않는다. 기존 접수 신고 증거는 별도 보존된다.
- 방의 chatDeletionRevision 변경으로 읽어둔 과거 채팅 페이지를 무효화하고 서버에서 최신 페이지를 다시 조회한다. 삭제 기능을 모르는 구버전에서는 새로 조회하기 전 과거 화면이 남을 수 있으므로 구버전 호환성을 실기기로 확인한다.
- 일반 채팅 초안/미확인 요청 ID와 본인 텍스트만 계정·방별 기기 내부 AES-GCM 암호화 저장. Android Keystore 키, 로그아웃/계정 삭제 시 삭제. 복구한 미확인 메시지는 자동 재전송하지 않고 사용자가 동일 요청으로 재시도한다. 저장에 실패하면 새 전송을 시작하지 않는다. 초안 쓰기는 비동기 디스크 저장이라 갑작스러운 전원 종료 직전 작성분까지 보장하지 않는다.
- 서버 배포 전 운영 callable 호환성 검사에 deleteRoomMessage를 포함한다. 운영 Firebase·Play 변경은 수행하지 않는다.
- UI/Android Keystore 복구, 프로세스 종료, 키보드, 오래된 메시지 삭제, 신고·차단, 응답 유실/재시도, 다중 기기에서 삭제 확인은 TS-10 및 실계정 QA 필수.
