# TS-R2-01 데이터 접근 권한 1차
- 방 목록, 방/멤버, 게임 세션과 게임 채팅은 MetadataChanges.INCLUDE로 서버 확인 전 캐시를 표시하지 않는다. 확인된 뒤 cache-only 전환이면 정보 제거 및 재연결 안내. 과거 게임 채팅은 Source.SERVER 조회 및 만료시각 필터.
- 방 목록 오류 시 선택 방과 목록을 제거하고 이전 listener generation을 무효화한다. 게임 접근 오류 시 세션·개인 역할·채팅·대기 행동을 제거하고 이전 응답을 무효화한다.
- 계정 삭제 요청이 있는 사용자와 종료된 방의 activeMember Rules 접근을 제한. 기존 서버 검증 및 개인 원본 비공개 유지.
- 프로필은 서버 확인 후 로드. 세부 캐시·계정 전환·네트워크 단절·복구는 최종 기기 테스트 필요.
- 대량 계정 삭제 분할 작업 및 공동 결과 익명화는 별도 후속 변경. 운영 Firebase/Play 변경 없음.
